# RSVP-приглашения — локальный MVP

## Маршруты

- `/invite/create` — создание события.
- `/invite?event=<public_slug>` — публичное приглашение и ответ гостя.
- `/my-event#token=<manage_token>` — приватный кабинет родителя.

Приватный токен находится после `#`: браузер не отправляет его в HTTP-запросе и серверных логах.

## Локальная разработка

На `localhost` данные хранятся в `localStorage` под ключом `mishanya-rsvp:v1`. Это позволяет безопасно пройти полный сценарий без D1, Bitrix и внешних сообщений.

```powershell
npm run dev
```

Открыть `http://localhost:3003/invite/create`.

## Cloudflare Pages / D1

API находится в `functions/api/rsvp.js`, схема — в `migrations/0004_rsvp.sql`.

Перед production-публикацией:

1. Применить миграцию к базе `GIFT_DB`.
2. Добавить секрет `RSVP_DATA_SECRET` или оставить резервное использование существующего `GIFT_DATA_SECRET`.
3. Проверить `NEXT_PUBLIC_TURNSTILE_SITE_KEY` и `TURNSTILE_SECRET_KEY`.
4. Пройти создание, ответ и повторное изменение ответа на production-like Pages preview.

При настроенном `TURNSTILE_SECRET_KEY` API отклоняет запросы без корректного Turnstile-токена.

## Приватность

- Страницы RSVP имеют `noindex` и `nofollow`.
- Ссылка управления отделена от публичной ссылки.
- Данные события и личные поля ответов шифруются перед записью в D1.
- Телефон гостя не запрашивается и не сохраняется.
- Для изменения ответа с того же устройства браузер хранит отдельный случайный ключ приглашения; в D1 записывается только его хеш.
- Гости не создаются как лиды Bitrix24.
